Meeting Pipeline

Paste a transcript (or a Loom link), and the pipeline extracts decisions and action items, checks every item against the transcript for receipts, and creates Jira tickets for human review. Optionally it also writes a strategy document to Confluence — a synthesis, not minutes.

Same transcript, same model. Naked runs get one generic prompt and no guardrails. Shelled runs go through the pipeline: strict prompt, schema gate, verbatim-evidence check. Each dot is one run; height is how many tickets it decided to create.
